# 海外经营看板指标口径（基于 1109 / 1116 历史样例）

> 以下口径反映历史 HTML/Excel；如果新模板或用户要求不同，应先确认并记录差异。**库存金额不是销售收入，销量快照增量不是现金回款。**

## 原始字段与月份
HTML 数据字段 `m7`、`m8`、`m9`、`m10` 在历史代码中显示为 **8、9、10、11 月实际**，不是 JavaScript 变量名直觉上的 7–10 月。 `avg710` 对应**8–10 月均销量**。不能根据字段名臆测月份。

## N3 MAX
- 11 月达成率：`m10 / fcst10 × 100%`。FCST 缺失或 `<=0` 时显示 `-`，不产生 Infinity。
- 达成率颜色：历史页面 `>=100%` 绿色，`>=50%` 且 `<100%` 黄色，`<50%` 红色。
- 库存合计：**FBA（含在途）+ 海外仓（含在途）+ 国内仓 + 未生产订单**。
- `transit` 在途总单列展示，**已经体现在 FBA 或海外仓中，不再相加**。
- 汇总行对产品/国家明细求和，平均销量可保持精度；多个型号同国家分别列出。

## EOL
- `EOL_COUNTRY` 为型号 + 国家明细；`EOL` 按产品大类汇总；不要叠加“汇总 + 国家明细”。
- **总库存（不含售后仓）**：FBA + 海外仓 + 国内仓 + 未生产订单；优先核对模板 P 列的源值。
- **售后仓可售**：`refurb_new + refurb_used`。
- **售后仓待翻新**：`refurb_pending`，不计入当前可售总库存。
- **库存合计（含可售售后仓）**：`total_after = total + refurb_new + refurb_used`。
- **库存金额**：以模板 S 列为主，`refurb_cost` 来源 V 列单独展示；不自行把两个金额重复相加。
- **不可售**：取模板 Q 列；不要假设它等于“待翻新”。
- **周转天数**：当 `avg710 > 0` 时，`total / avg710 × 30` 天；`avg710<=0` 时无有效周转天数。
- **历史分类逻辑**：月均销量 `<10` 且总库存 `<300` → 清仓；总库存 `>500` → 推动销售；部分特殊 SKU 不展示清仓/周转，部分特殊 SKU 只展示周转，周转天数 `>500` 时不展示；其余展示周转天数。**例外优先级以实际 HTML 源码为准，修改前需回归验证。**
- FBA / 海外仓在途、售后仓“全新/二手/待翻新”不可重复入账。

## 快照对比
- `delta = new - old`，变化率 `(new-old)/old`，旧值为 0 时应显示 `N/A`。
- 11 月累计销量两个快照相减得到的是**累计销量净增量**，不能直接称作周销售或环比。
- 如果源文件补录、退货、调整 SKU 范围或单位，必须给出口径变更提示。
- 数据行数或产品/国家范围不一致时，先归一化可比样本，再做驱动分析。

## 不可修改的风险点
1. `transit` 不二次叠加。
2. 全新+二手可以纳入可售库存，待翻新不计入。
3. `total` 与 `total_after` 明确区分。
4. 成本/库存金额与销量/回款明确区分。
5. `SKU + model + country` 粒度与按 `major` 归并的口径不混淆。
