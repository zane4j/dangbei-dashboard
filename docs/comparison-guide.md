# 看板版本对比与分析方法

基于历史《海外经营看板对比分析_1109与1116.docx》的**方法论**整理；不在公开仓库存储报告中的真实经营数字。

## 比较步骤
1. 记录两期快照的日期、Excel 文件版本、来源及同步时间。
2. 先比较 SKU 型号、国家、明细行范围；确认期间业务口径一致。
3. 从 N3 与 EOL 独立计算：总库存、库存金额、累计销量、不可售、售后仓、达成率及周转。
4. 分析数量差与金额差的方向；区分“销售消化”和库存调拨/数据补录/价格变动等其他原因。
5. 按国家与 SKU 识别增量贡献；标注分母、权重、可比国家范围。
6. 单列 N3 FCST 达成率、EOL 库存积压及清仓/推动销售名单。
7. 将结果总结为“核心结论 → 整体变化 → N3 → EOL → 风险/行动建议 → 数据口径说明”。

## 对比表格式
| 指标 | 旧快照 | 新快照 | 绝对变化 | 变化率/备注 |
| --- | ---: | ---: | ---: | --- |
| 总库存 | 取旧模板 | 取新模板 | 新 - 旧 | 需控制 SKU 范围 |
| 库存金额 | 取旧模板 | 取新模板 | 新 - 旧 | 非现金回款 |
| 11 月累计销量 | 取旧模板 | 取新模板 | **累计销量净增** | 不是“周销量” |
| 不可售库存 | 取旧模板 | 取新模板 | 新 - 旧 | 核对状态口径 |

## 常见误判
- 看到库存金额下降就推断已实现销售或现金回流。
- 把两次累计销量的差称为严格“周销量”。
- 将“在途”与“含在途的 FBA/海外仓”重复加总。
- 忽略 SKU、Bundle 或国家范围变化。
- EOL 待翻新库存计入当前可售。
- 把 8–10 月均销量的浮点精度变化当成历史销量增长。
