# 更新前后 QA Checklist

## 输入与安全
- [ ] 原 Excel 和旧 HTML 已备份，输出使用新日期版本

- [ ] 明确真假数据、企业敏感信息和仓库的公开/私有属性

## Excel → DATA
- [ ] 数据行数、SKU 数、国家/地区数一致
- [ ] 允许一国多型号，不产生重复 `major/model/country`
- [ ] 读取的是明细行，未把第 3 行汇总再次累加
- [ ] 8–10 月实际、均销量和 11 月实际/FCST 对应正确

- [ ] 小数与人民币金额保留源数据精度，显示层再格式化

## 业务口径
- [ ] N3 各月销量合计、FCST、达成率与模板核对
- [ ] FBA + 海外仓 + 国内仓 + 未生产订单与总库存核对
- [ ] 在途总未重复计入
- [ ] EOL 总库存不含售后仓，`total_after` 含全新/二手不含待翻新
- [ ] 不可售数量、金额及售后仓金额独立核对

## 页面回归
- [ ] N3 / EOL 页签可切换
